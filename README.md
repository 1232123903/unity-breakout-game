## Features 

* **Classic Gameplay:** Destroy all the bricks by preventing the ball from falling past your paddle.
* **Lives System:** The player starts with 5 lives (displayed in the top-left corner).
* **Live Score Tracking:** Dynamic real-time score display (displayed in the top-right corner).
* **Grid Layout:** Multiple layers of bricks with smooth color gradients.
* **Smooth Controls:** Responsive paddle movement for precise ball deflection.

---


  ## Controls

  * **A/D -> Move Left/Move Right**

## Tech Stack & Architecture

* **Engine:** Unity
* **Core Logic / Language:** C++ (Native integration / Bindings)
* **Rendering / UI:** Unity Graphics / Canvas

## Getting Started 

Follow these steps to set up and run the game locally on your machine: 

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/1232123903/unity-breakout-game.git](https://github.com/1232123903/unity-breakout-game.git)
   
  1. Open in Unity: 
    Open Unity Hub.
    Click on Add project from disk and select the cloned folder.
    Make sure you open it with the compatible Unity version.
  
  2. Build and Run:
     Open the Main Scene (Scenes/GameScene.unity or equivalent). 
     Press the Play button in the Unity Editor to run the game.
  ```
